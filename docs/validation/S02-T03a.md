# S02-T03a — Material library without presentation media

Recorded 2026-10-18 UTC. **Completed.** The campaign server loads the real
material library and every material pair. Pair sounds and wallmarks are not created.
This is a load-time result only: no collision, physics step or sound stimulus has
run. Parent S02-T03 stays In Progress.

## Problem

`CGameMtlLibrary::Load` loads each `SGameMtlPair` (`xrEngine/GameMtlLib.cpp:222-231`).
`SGameMtlPair::Load` creates `ref_sound` objects through the sound manager, and
wallmark shaders through the render resources (`GameMtlLib_Engine.cpp:27-60`,
`107-139`). The `material_pairs.ltx` override path does the same through
`CreateSoundsImpl/CreateMarksImpl` (`GameMtlLib.cpp:236-321`). With no sound
manager, `smoke-12` crashed in `CreateSounds`
([S02-T02 context validation](S02-T02-context.md)).

## Change

Patch `0004-materials-without-media.patch`
(SHA-256 `8f04c72238bdae564bfe765d8249457bef2a6832a02f0a467be80e2e710d5244`):

- `CGameMtlLibrary::SetPresentationMedia(bool)`, default `true`. When it is off:
  - Pair loading still stores every media name: `BreakingSoundsStr`,
    `StepSoundsStr`, `CollideSoundsStr`, `CollideParticlesStr`, `CollideMarksStr`.
  - Pairs still get their (empty) factory wallmark array.
  - No sounds are created, and no wallmark shaders.
  - The override path follows the same rule.
- The client never calls the setter, so its behaviour is unchanged.
- **Campaign smoke:** a `materials` service between `spatial-db` and
  `script-engine`, matching the native order (materials load at persistent app
  start, before game globals). The service checks four things:
  - the material count is nonzero
  - the pair count is nonzero
  - some pairs carry media names
  - **no** media was created
  It turns `GMLib.Load`'s silent missing-file return into a stage failure. A check
  that fails after loading unloads the library before reporting.

The full series reconstructs all 12 changed files in
`builds/stage2/patch-check-05b` (`builds/logs/patch-reconstruction-05.json`,
produced by the new `tools/export-engine-patch.py`).

## Limits and obligations

- **Override path untested at runtime.** The installed data has no
  `material_pairs.ltx`, so that path is guarded but never ran.
- **Sounds still matter to gameplay.** Collision, step and breaking sounds are
  also AI hearing stimuli (S02-T01 B18). Several gameplay callers pick from
  these sound vectors: `PHSoundPlayer`, `step_manager`, `material_manager`,
  `ai_monster_defs` and `poltergeist_ability`. They must get stimulus metadata
  from the stored names (S02-T05) and must not index an empty vector. Wallmark
  callers in `physics_game.cpp:280` and `Level_bullet_manager_firetrace.cpp:185-208`
  already skip an empty mark array.
- **Client.** It was built but not run interactively. Its default keeps the
  original media creation.

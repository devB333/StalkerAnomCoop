**Defect (qx-2): tasks recovered from a checkpoint could not complete.**
The native task manager loads tasks without a co-op owner, and S03-T02's
guard refuses an unowned task's checks while two actors exist, so the
recovered party task (and every other task loaded from a save) could never
complete after a restart. **Fix:** at serving start every unowned loaded
task is given to participant 1 (the native save is participant 1's actor's;
participant 2's tasks are not in it, L32), and the party's task is rebuilt
from the recovered world (`rebuild_party_tasks`: the instance number from
the anchor's portable store). qx-4 shows the window now recovers and
completes.

The comparison tool learnt to check **progress as well as safety**
(`retry_completes`): qx-2 passed every safety check (nothing acknowledged,
money rolled back) while the quest could never be finished.

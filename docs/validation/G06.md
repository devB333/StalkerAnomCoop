## What is not covered (carried)

- **Not a playable campaign.** Movement, fire, reload and activate-slot reach
  the server; use, pick-up, jump, lean, inventory moves, trade and dialogue
  do not (L01). A weapon knocked out of a player's hand cannot be picked up.
- **Deaths are in memory only** (plan.md S06-T05 risk): no persistence of
  a death until Stage 7. What a dead player does next (respawn, spectate,
  reload) is not designed.
- **Hits are resolved at the server's present time**, no lag compensation; a
  moving target must be led by the round trip plus the 100 ms render delay.
- **One weapon (PM), one monster type (boar), one companion NPC** (Fanat).
  The killer of a body is not replicated, NPC animation state is not
  replicated (S10-T02), ownership and inventory changes are not replicated
  (S08).
- **No level change** (L14): the server and clients now refuse level-changer
  touches and `M_CHANGE_LEVEL` (S06-T05, enc-9 crash). Stage 9 owns
  transitions.
- **Installed scripts still decide for actor 0** in places (L11): the
  installed death game modes (Azazel, Ironman) do not run for participants;
  `xrs_facer` (NPC melee) drops a hit player's weapon, as in single player.
- One Windows host, loopback, simulated impairment only (L16); sessions under
  5 minutes (L21).
- **Fixture behaviour:** the boar's AI decides whether it attacks (8 of 10
  runs); Fanat, player 1's companion, follows actor 0, fights, and his melee
  (`xrs_facer`) drops a punched player's weapon. Fixture runs are therefore
  not all-pass every time; the failures seen were fixture outcomes, not
  divergence.
- Open defects: the GameState smoke activity fixture (L23); the rare client
  access violation at exit (L24). The single-player capture "stall"
  (S06-T02, S06-T05) was the "Press any key" screen and is fixed in the
  capture harness.

## Decisions for the user

1. **Friendly fire:** on by default (`friendly_fire = 1`), the same rule both
   ways. Keep it on, make it off by default, or make it a session option?
2. **A dead player:** today the body stays dead and the client shows the
   death camera with no game over. Respawn, spectate-until-revive or reload a
   checkpoint is unplanned; which should a later task design?
3. **Installed death game modes** (Azazel, Ironman) hook the before-death
   callback, which no longer runs for participants. Accept that for now, or
   add a task to support them?
4. **Fixture level:** the fixtures run in `k00_marsh` with Fanat, whose
   companion behaviour (following actor 0, fighting, melee) keeps
   interfering with the programs. Keep the marsh fixture (with Fanat), or
   move later fixtures to Cordon or another quieter spot?
5. **Storm visuals:** storms and emission effects are not replicated (L09,
   S10-T05). Keep them in S10-T05, or add a small earlier task?

## New limits (added to [carried limits](../carried-limits.md) as L28–L31 on acceptance)

- Deaths in memory only; dead-player flow undecided (owner: Stage 7 for
  persistence, a new task for the dead-player flow).
- No lag compensation for hits (owner: S11 or a new task if play tests need
  it).
- The killer of a body and an NPC's last hitter are not replicated (owner:
  S08 presentation).
- Fixture NPC interference (Fanat's following and melee weapon drop; the
  boar's choice to attack) (owner: the fixture question below; S11-T02 for
  the test harness).

## User decision

On 2026-10-21 the user answered the five decisions above, which this record
takes as acceptance of G06 for development:

1. **Friendly fire stays on** (`friendly_fire = 1`, the same rule both ways).
2. **A dead player respawns after a prompt** at their last save or autosave
   position, or where the server last tracked them, and **their corpse
   persists so they can loot it**, as in the installed Azazel mode. New task
   S07-T07 (needs S07-T02's checkpoints for the save position; looting the
   corpse needs S08-T02's transfers).
3. **Azazel and Ironman are unavailable in co-op.** Accepted scope; no task.
4. **Test in Cordon from now on, without Fanat.** New task S06-T06: a Cordon
   (`l01_escape`) fixture save with Fanat removed from the fixtures, and the
   Stage 6 programs moved to it.
5. **Storm and emission visuals synced as soon as it makes sense.** New task
   S06-T08 (presentation: rain, wind, thunder and lightning, the emission's
   sky, sound and camera effects from the server's state). The emission's
   gameplay (cover, damage) stays with S10-T05.

The user also asked when pick-up, inventory, trade and jump arrive: pick-up
is S08-T01, transfers S08-T02, trade S10-T04 (they need durable ownership
first); jump and lean had no task and are now S06-T07.

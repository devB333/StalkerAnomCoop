## What the scripts do (source)

- **Guides** (`ka_travel.script:53-84`): the dialogue action `travel_to_*`
  breaks the talk, pays the guide `ceil(distance / 10) × 100` through
  `dialogs.relocate_money_from_actor` (`dialogs.script:1829`, an
  `transfer_money` to the NPC), skips `distance / 1000` hours plus 0–2 h and
  1–59 min with `level.change_game_time`, then calls `ChangeLevel` to the
  smart terrain. In co-op the dialogue runs on the server in the player's
  context (S10-T04a): the fee went, the **whole world's time skipped**, and
  the native level change was refused on the server (L14), so nobody moved.
- **Fast travel** (`game_fast_travel.script:47-123`) and the **backpack**
  (`game_backpack_travel.script:32-94`) run in the client's PDA map menu: the
  same checks (combat, weight, bleeding, emission), a time skip, then
  `set_actor_position` on the same level or `ChangeLevel` to another. On a
  co-op client the skip was local (stepped back by the server's clock), the
  jump was undone by the server's state, and `ChangeLevel` (a timed event on
  a replica that runs no actor update, then `M_CHANGE_LEVEL`, refused, L14)
  did nothing.
- `ChangeLevel` (`_g.script:406-446`) sends `M_CHANGE_LEVEL` with the game
  vertex, level vertex, position and angles; `level.change_game_time` is
  `level_script.cpp:322`; `set_actor_position` is
  `CScriptGameObject::SetActorPosition` (`script_game_object2.cpp:363`).

## What was built

- **Time skips held** (`level_script.cpp` `change_game_time` →
  `campaign::defer_game_time_change`): on a co-op client a script's skip is
  only noted (the server's clock rules); on the server a skip asked in a
  player's context is held for the tick (`time-skip-held`); a travel request
  in the same tick takes it, otherwise it is applied one tick late as the
  script asked (`time-skip-applied`, T03d-5). The server's own skips run
  under `GameTimeChangeDirect`.
- **Server (guides)**: the compat layer wraps `ChangeLevel` (in a player's
  context it becomes `campaign.relocate`) and
  `dialogs.relocate_money_from_actor` (notes what actually left the purse,
  `campaign.note_fee`); `coop_server_relocate` proposes a travel to the point
  with the held skip and the noted fee (source 4); a refused request refunds
  the fee at once.
- **Client (fast travel, backpack)**: at world-live `ChangeLevel` is wrapped
  to call `campaign.client_relocate`; `SetActorPosition` on the own actor
  calls `coop_client_relocate_actor` (the point's level and game vertices
  from the level graph and cross table); both send **ActionIntent 26**
  (`relocate`: game vertex, level vertex, position, the noted skip's minutes,
  source) and say *"Asking your partner to travel there..."*; refusals are
  said in plain words.
- **Server (both)**: `relocate_propose` (`CoopServerHost.cpp` "S10-T03d"): the
  travel request's checks without a changer (busy, partner present, combat,
  a valid game vertex, a valid level vertex on the same level); the
  proposal is the travel coordinator's (CampaignEvent 13, answers kind 12),
  `tv.relocation` with the point, the minutes and the fee. `relocation_end`:
  agreed, the trip's time skips once (with the scripts'
  `time_forwarded` flags and a forced weather change) before the executor's
  barrier; otherwise the fee is refunded. The S09 executor carries it out,
  a same-level point included (the level reloads with both actors at the
  point; no long live move, so L58 does not arise).
- **Fixture** `--relocate c1,c2` (profile `relocate_party`,
  `relocate_fixtures`): variant 0, a guide's action in player 2's context
  (fee 1000 to the nearest stalker, a 2 h 30 min skip, `ChangeLevel` to a
  Darkscape smart terrain), refused by player 1, then agreed; variant 1
  (`--relocate-variant 1 --relocate-test c2:40`), client 2 does what a
  same-level fast travel does (`level.change_game_time(0, 1, 0)`, then
  `set_actor_position` to a point ahead), player 1 agrees.
  `tools/compare-coop-relocate.py --variant 0|1`.

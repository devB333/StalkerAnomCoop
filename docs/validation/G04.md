## What is not covered (carried)

- **One machine, loopback only.** All network evidence uses real UDP sockets
  and the full GNS stack on 127.0.0.1, with GNS's simulated loss and lag. No
  LAN, internet, NAT or firewall test; no claim of internet reachability
  (R06). Owners: S05 (two real clients), S11-T01.
- **Active man in the middle.** The handshake runs inside unauthenticated GNS
  encryption; an attacker on the path who relays a live handshake keeps the
  session (R06, G11). Strangers, eavesdroppers, the other player and replays
  are stopped.
- **No sanitizer** in the pinned toolchain. Races were checked by repetition
  and invariants; the codec fuzz used guard pages.
- **Not in the engine yet.** Linking the libraries into the campaign server
  and client, computing the build and content digests, attaching sessions to
  participant slots, applying the detached-actor policy, and the headless
  server's power throttling (S04-T01 finding 5) all belong to S05-T01.
- Timeout defaults are provisional (S11-T01). protobuf 3.21.12's age (S04-T01).
  Fake-backend simplifications are listed in `fake_network.h`.
- Entity generation mapping on the wire (S05-T02); snapshot components beyond
  the first set (S06-T02).
- The G01 waivers and the G02/G03 carried limits are unchanged.
